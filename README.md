## 🌟 Key Highlights

### 1. B2C Video-First Social Marketplace
- 🎥 **Shoppable 9:16 Reels Feed:** Fluid short-form video discovery featuring Egyptian fashion designers and artisans.
- 🛍️ **Unified Multi-Merchant Marketplace:** Multi-brand cart with localized Egyptian payment options (InstaPay, COD, Cards).
- 🎁 **Tiered Loyalty & Rewards:** Point accumulation and cash-back discounts across the entire network.
- 🤝 **Creator UGC Collaboration Hub:** Video submission, campaign escrow, and automated affiliate commissions.

### 2. B2B Multi-Tenant Merchant SaaS Engine
- 🏬 **Independent Boutique Subdomains:** Instant provisioning for `talieska.eg-commerce.com`, `khan-craft.eg-commerce.com`, and custom CNAME domains with SSL.
- 🎨 **Full Storefront Theme & Layout Builder:**
  - 3 Theme Modes: *Dark Luxury*, *Atelier Light*, *Midnight Velvet*.
  - Curated luxury color palettes (Crimson Red `#d00000`, Pharaoh Gold `#feb700`, Nile Emerald `#10b981`).
  - 3 Hero section layouts (*Wide Cinema*, *Split Editorial*, *Minimal Card*).
  - 10 Independent Section Visibility Toggles + Trust Pillars Text Editor.
  - Real-time responsive device simulator (**Desktop** vs. **Mobile**).
- 📦 **Smart Inventory & Real-Time Unit Economics:**
  - Calculates Retail Price vs. COGS, Net Profit, and Profit Margin % live.
  - Fast-stock increment buttons and Egyptian fashion size matrix (`S` to `Free Size`).
  - One-click Marketplace Syndication switch (*"Private to my boutique"* vs. *"Syndicate to central Reels"*).
- 🚚 **Egyptian Logistics & Payments Layer:**
  - Integrated **Bosta Express** thermal shipping label (AWB) generation.
  - **InstaPay** bank transfer verification modal.

## 🛠️ Quick Start

```bash
# Clone the repository
git clone https://github.com/Moasy1/EG-Commerce.git

# Enter project directory
cd EG-Commerce

# Install dependencies
npm install

# Run the development server
npm run dev
```

Visit `http://localhost:3000/` in your browser.

---

## 📦 Build for Production

```bash
npm run build
npm run preview
```
